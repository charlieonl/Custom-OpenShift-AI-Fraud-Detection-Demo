# Upstream source

The training, validation, and test CSV files used by this demo come from:

https://github.com/rh-aiservices-bu/fraud-detection

Only these upstream files are required by the two demo notebooks:

- `data/train.csv`
- `data/validate.csv`
- `data/test.csv`

The rest of the upstream workshop notebooks, pipeline examples, Ray/KFTO scripts,
feature-store material, setup helpers, and workshop assets are intentionally omitted
from this reusable Meridian demo package.
